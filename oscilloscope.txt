3. Connections
Use the following connections for a typical ADS1115 breakout board.
ADS1115 pin	Raspberry Pi connection
VDD	3.3V, physical pin 1
GND	GND, physical pin 6
SDA	GPIO2 / SDA, physical pin 3
SCL	GPIO3 / SCL, physical pin 5
A0	Analog signal input

4. Enable I²C communication
The ADS1115 communicates with Raspberry Pi using I²C.
sudo raspi-config

Then select:
1. Interface Options
2. I2C
3. Select Yes to enable it.
4. Exit and reboot:

sudo reboot

import time
import board
import adafruit_ads1x15.ads1115 as ADS
from adafruit_ads1x15.analog_in import AnalogIn
import matplotlib.pyplot as plt

# Initialize I2C
i2c = board.I2C()

# Initialize ADS1115
ads = ADS.ADS1115(i2c)
ads.data_rate = 128

# Select analog input A0
channel = AnalogIn(ads, ADS.P0)

try:
    while True:
        voltages = []

        # Collect 100 readings
        for i in range(100):
            voltages.append(channel.voltage)
            time.sleep(0.01)

        # Plot the readings
        plt.clf()
        plt.plot(voltages)
        plt.title("ADS1115 Oscilloscope")
        plt.xlabel("Sample Number")
        plt.ylabel("Voltage (V)")
        plt.grid(True)
        plt.pause(0.1)

except KeyboardInterrupt:
    print("Program stopped")

finally:
    plt.close()
