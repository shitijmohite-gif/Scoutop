3. Hardware connections
For a typical single-channel relay module with a 3.3V-compatible input:
Relay module	Raspberry Pi
IN	GPIO17, physical pin 11
GND	GND, physical pin 6
VCC	According to the relay module specifications

5. Create the Python program

from flask import Flask, render_template_string, redirect, url_for
from gpiozero import OutputDevice

app = Flask(__name__)

# Change active_high if your relay works in reverse
relay = OutputDevice(17, active_high=False, initial_value=False)

HTML = """
<!DOCTYPE html>
<html>
<head>
    <title>Raspberry Pi Relay Control</title>
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <style>
        body {
            font-family: Arial;
            text-align: center;
            margin-top: 60px;
            background: #f2f2f2;
        }
        .card {
            background: white;
            padding: 25px;
            margin: auto;
            max-width: 350px;
            border-radius: 12px;
        }
        button {
            padding: 12px 25px;
            margin: 8px;
            font-size: 16px;
            cursor: pointer;
        }
    </style>
</head>
<body>
    <div class="card">
        <h2>Relay Control Dashboard</h2>
        <h3>Relay Status: {{ status }}</h3>
        <form action="/on" method="post">
            <button type="submit">Turn ON</button>
        </form>
        <form action="/off" method="post">
            <button type="submit">Turn OFF</button>
        </form>
    </div>
</body>
</html>
"""

@app.route("/")
def home():
    status = "ON" if relay.value else "OFF"
    return render_template_string(HTML, status=status)

@app.route("/on", methods=["POST"])
def turn_on():
    relay.on()
    return redirect(url_for("home"))

@app.route("/off", methods=["POST"])
def turn_off():
    relay.off()
    return redirect(url_for("home"))

if __name__ == "__main__":
    try:
        app.run(host="0.0.0.0", port=5000, debug=False)
    finally:
        relay.off()
        relay.close()

6. Run the program
Activate the virtual environment:
source ~/flask-env/bin/activate

Run the application:
python relay_dashboard.py

Find your Raspberry Pi's IP address:
hostname -I
