4. Check the camera
Open the terminal and run:
rpicam-hello

To capture a photo directly from the terminal:
rpicam-still --output image.jpg

To record a 10-second video:
rpicam-vid -t 10000 --codec h264 -o video.h264

5. Install the Python library
Run:
sudo apt update
sudo apt install -y python3-picamera2


6.python program
from picamera2 import Picamera2
from picamera2.encoders import H264Encoder
from picamera2.outputs import FileOutput
import time

# Initialize camera
camera = Picamera2()

# Configure camera for preview and capture
camera.configure(camera.create_preview_configuration())

# Start camera
camera.start()
time.sleep(2)

# Capture image
camera.capture_file("image.jpg")
print("Image captured successfully!")

# Record video for 10 seconds
encoder = H264Encoder()
camera.start_recording(
    encoder,
    FileOutput("video.h264")
)

time.sleep(10)

camera.stop_recording()
print("Video recorded successfully!")

# Stop camera
camera.stop()
7. Run the program
python3 camera_practical.py
